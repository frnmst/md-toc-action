# Security Policy

<!--TOC-->

## Supported Versions

The latest
[GIT tagged version of md-toc-action](https://github.com/frnmst/md-toc-action/tags) is the
only one supported. When a new version is released, that one will be the only
one supported.

## Reporting a Vulnerability

Send me an [email](mailto:solvecomputersciencecollabs+SECURITY-md-toc-action@gmail.com?subject=report%20md-toc-action%20vulnerability&body=Please%20encrypt%20before%20sending), preferably encryped.
